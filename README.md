📌 Overview

This repository contains three Python projects developed as part of my Python Programming Internship with CodeOrbit Tech. These projects demonstrate fundamental programming concepts, problem-solving, error handling, and file management.

💻 Projects

1. Simple Calculator

A command-line calculator that performs basic arithmetic operations.

Features:

- Addition, subtraction, multiplication, and division
- User input validation
- Exception handling
- Division-by-zero prevention

File: "calculator.py"

2. Number Guessing Game

An interactive game in which the computer generates a random number between 1 and 100, and the user attempts to guess it.

Features:

- Random number generation
- Higher and lower hints
- Attempt counter
- Input validation
- Win message upon guessing correctly

File: "guessing_game.py"

3. To-Do List CLI Application

A task management application that allows users to organize daily activities through a command-line interface.

Features:

- Add new tasks
- View tasks with numbers
- Remove tasks
- Save tasks to a text file
- Load previously saved tasks
- Handle invalid inputs

File: "todo_list.py"

Data file: "tasks.txt" (created when tasks are saved).

⚙️ Installation and Execution

Prerequisites

- Python 3 installed on your system
- Visual Studio Code or another Python editor

Run the Projects

Download or clone this repository and open the project folder in your terminal.

Simple Calculator

python calculator.py

Number Guessing Game

python guessing_game.py

To-Do List Application

python todo_list.py

On Windows, you can use "py" instead of "python" if necessary.
